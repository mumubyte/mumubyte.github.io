Windows 11 创建共享文件夹

Windows 11 上用 SMB 协议把本机文件夹共享给局域网其他设备，图形界面点几下就能完成，真正容易踩坑的是权限模型和几个默认收紧的安全策略。这篇从零走一遍，并把 24H2 之后的行为变化标出来。

# 前置条件

  • 修改Windows11的高级网络共享设置，如下图

  • 设置本地策略，如下图

  • 设置Windows 网络策略，启用不安全的来宾登录

  • 启用smb 1.0

# 方法一：快速共享（简单共享）

  1. 右键目标文件夹 → 属性 → 共享 选项卡
  2. 点击 共享(S)... 按钮
  3. 下拉框选择用户（可选 Everyone，或点「添加」输入本机用户名）→ 添加
  4. 设置权限级别：读取 / 读取和写入
  5. 共享 → 完成

完成后记下窗口里显示的 \\计算机名\共享名 路径。

这种方式共享名默认等于文件夹名，权限只有读/读写两档，且会同时授予 NTFS 权限。

# 放行网络与防火墙

1. 打开网络发现和文件共享

设置 → 网络和 Internet → 高级网络设置 → 高级共享设置：

  • 专用网络：启用 网络发现、启用 文件和打印机共享
  • 所有网络：密码保护的共享 建议保持开启（关闭等价于允许来宾访问，见下文）

2. 放行防火墙规则

控制面板 → Windows Defender 防火墙 → 允许应用或功能通过 Windows Defender 防火墙 → 勾选 文件和打印机共享，且确认「专用」列已勾选。

对应入站规则为 文件和打印机共享 (SMB-In)，端口 445。

# 其他

  • SMB1 已默认不安装，沿用 SMB2/3。若老设备只支持 SMB1，应升级设备而不是装回 SMB1
  • 家庭版没有 gpedit.msc 和 lusrmgr.msc（本地用户和组），前者用注册表替代，后者用 net user 命令替代
  • 共享权限里添加用户时，家庭版无法从「本地用户和组」挑选，需要手动输入 计算机名\用户名
